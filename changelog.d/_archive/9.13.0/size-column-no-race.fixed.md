# 仓库大小列不再永久空白（「算完即回填」替代「600ms 猜」）
原实现起后台线程算各仓库目录大小，然后 QTimer.singleShot(600, 读结果) —— 那是**猜**算完的时间。实测 15 万文件要 484ms、机械盘/杀软下更久；一旦超过 600ms 读到的就是空列表且**不再重试** → 大小列永久空白，用户以为功能坏了。
改为线程算完 emit 信号（Qt 队列切回 GUI 线程）真正的「完成即回填」；另加 5 分钟 TTL 缓存 + 刷新时清缓存，不再每次刷新都全量递归 scandir。
@verify tests/test_c2_ux.TestSizeColumnNoRace（4 例：信号已连 / 源码里不得再有 600ms 猜测调用（AST 判定）/ 回填写模型 / 缓存可清）
