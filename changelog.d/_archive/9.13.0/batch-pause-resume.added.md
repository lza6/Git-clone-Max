# 批次级暂停/继续：挂机中途可以「先停十分钟」
原来只有「单仓库暂停」和「取消全部」两档，中间档缺失 —— 挂着刷几百个仓库时想暂停一下只能取消重来（丢进度）。现下载页有「暂停/继续」按钮：暂停=不再从待发队列取新任务、在途的跑完即止（不丢进度、不终止任何任务）；继续=立刻补满到当前并发上限。
事件流新增 batch_paused / batch_resumed（已登记进 EventType.ALL，否则 SSE 过滤会漏）。
