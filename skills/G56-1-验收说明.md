# G56-1 技能包 v1 验收说明（M13 生态 agent 化）

五个技能包位于仓库 `skills/`，每包 SKILL.md + scripts/ + 本文档汇总验收。
所有脚本走项目现有 CLI（含 `--json`），不直接操作 PyQt6 UI。

## 包清单与命令

| 包 | 目录 | 主命令 | 输出 |
|----|------|--------|------|
| gcm-clone | `skills/gcm-clone/` | `python -m gcm --cli [--json] --dir <out> <urls.txt>` | 克隆结果 JSON（契约 §2） |
| gcm-archive | `skills/gcm-archive/` | `python skills/gcm-archive/scripts/archive-list.py <urls.txt> --out ./zips` | 归档 zip + JSON |
| gcm-report | `skills/gcm-report/` | `python skills/gcm-report/scripts/export-report.py --out ./reports --format csv` | CSV/Markdown + JSON |
| gcm-diag | `skills/gcm-diag/` | `python -m gcm --cli --diag [--json]` | 分级报告（绿/黄/红） |
| gcm-resume | `skills/gcm-resume/` | `python skills/gcm-resume/scripts/resume.py <urls.txt> --dir <out>` | 续跑 JSON + summary |

## 统一契约（docs/agent-contract.md）

- 顶层：`{version, ok, counts:{success,failed,other,total}, results:[...], invalid:[...]}`；
- 错误对象：`{code, message, redacted}`；
- 退出码：0=全成功 / 1=有失败 / 2=无有效输入（MCP 未启用另为 3）；
- 打码：URL 内嵌凭据 / Authorization / PRIVATE-TOKEN 一律 `***`；
- 只读边界：report 只读数据源；archive/diag 不写库不改源码；clone/resume 只写 `--dir`。

## 遗留风险

- 五包脚本用 `sys.executable` 找解释器：在打包 exe 环境需改为打包路径；
- `gcm-archive` 的 zip 校验建议补 `zipfile.testzip()`（当前只验存在性）；
- `gcm-resume` 的「跳过」依赖引擎 `check_existing`（progress_path 为空时预检不触发，
  CLI 首次克隆已完成目录会直接 fetch 增量；语义仍是「不重复克隆」，验收项 2 已按此定义）；
- MCP/HTTP 的显式 enable 设置页 UI 接入由主控后续里程碑完成（本代理只交付 server + 测试）。
