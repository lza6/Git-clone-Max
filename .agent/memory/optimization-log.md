# 优化记录与基线（optimization-log）

## 测试耗时基线

| 项 | 耗时 | 备注 |
|----|------|------|
| 快集全量（1122 用例） | ~13 min | Windows 本机，含 coverage |
| 慢集（真实 git E2E） | ~6 min | CI 独立 `slow` job |
| 质量闸（ruff+mypy） | ~30 s | 每次改 gcm/ 必跑 |
| PyInstaller 构建 | ~10 min | 发版前 |

## 性能相关（历史）

- 本地扫描提速 ~95x（150s → 1.6s，v8.0.2）：纯文件读 + 线程池 + junction 跳过 + 批量事务写库。
- 日志渲染：`LogBuffer` 由「常驻 120ms 循环定时器」改为「有积压才武装的单次定时器」——
  空转不再唤醒事件循环（v9.4.0）。
- 引擎：并发 32 + 流控 64 惰性补投 + 250ms 行合并 + 100ms 进度心跳。

## 本轮（v9.4.5/v9.4.6）

- 移除测试运行器的 `gc.disable()`：不再整轮囤积循环垃圾（内存回落），
  且 CI 在正常 GC 下三平台全绿。
- 审计写盘加锁：并发 40 线程从「丢行/空行」变为 30/30 稳定。
