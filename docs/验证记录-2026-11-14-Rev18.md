### §4.1 test_manage_ui 偶发根治（本轮真实发现的第 7 个真问题）

现象：快集全量下 `test_check_update_new_version_asks_and_opens_browser` 偶发
（10 轮里约一半），单测复跑 3 连 FAIL 也复现——**不是负载问题**。

根因链（逐层实证）：
1. `MainWindow.__init__` 里 `QTimer.singleShot(2500, self._check_update_silent)` 捕获**构造时的绑定方法**；
2. 测试 setUp 事后置换实例属性 `self.w._check_update_silent = lambda` 拦不住定时器（定时器手里是原方法）；
3. 静默检查 → `check_silent` → `check_latest`（该 mock 命中）→ 但手动路径真实入口
   `check_latest_with_sha` **未被测试 mock**，其内部 sha 提取的 urlopen 真联网；
4. 本机网络对 GitHub API 快慢不定（防火墙），慢于 `_pump_until` 5s 窗口 → question 未弹 → FAIL。

修复（只动测试，生产代码零改动——生产行为正确）：
- setUp 类级短路 `_check_update_silent` 的定时器注册（其余 singleShot 原样放行）；
- 该用例补 mock `check_latest_with_sha`；断言从「m_check.called」修正为「question 弹窗文本」
  （两个入口都 mock 后前者不再成立）。
- 验收：**10/10 连跑全绿**。known-issues §已知不稳定 已登记根治详情。
