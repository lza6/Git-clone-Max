## 2. 关键改动

### 2.1 视觉系统分层（防"什么都塞 theme.py"）

- `gcm/ui/typography.py`：`FONT_STACK` / `FONT_STACK_DISPLAY` / `FONT_STACK_MONO`、
  `TYPE_SCALE`（display 28 / h1 20 / metric 18 / h2 15 / body 13 / mono 12 / small 11）、
  `type_px` / `type_font` / `apply_type`。**字距只能经 QFont**（QSS 无 `letter-spacing`）。
- `gcm/ui/palettes.py`：四套色板 + `TOKENS`（radius card 6 / control 5、spacing 加 `inset` 20 与
  `section` 40、`row.default` 26）+ 对比度工具。
- `gcm/ui/qss_build.py`：由色板/token/排版角色生成 QSS；`QWidget#rootBg` 单层垂直渐变，
  GroupBox `border-top` 内嵌高光（Qt 无 box-shadow），页签选中态用 accent + 700 字重，
  次级按钮改幽灵样式（`background: transparent`），`QToolTip` 统一主题色。
- `gcm/ui/theme.py`：只留主题状态 + 日志模型 + **22 个兼容再导出**（拆前先看
  `tests/test_g46_theme.py` / `test_themes.py` / `test_g70_ui_upgrade.py`）。

### 2.2 修掉的真实缺陷（本轮现测发现，非计划内）

1. **颜色双真相**：`_themed_qss` 应用了 `accent_preset`，但自绘 delegate / 日志高亮 / 托盘图标
   读的是未应用预设的 `current_palette()` → 批次进度条是旧 Primer 蓝 `#0969da`、行内进度条是新青。
   修法：新增 `apply_accent_preset()`，`_themed_qss()` 先写模块状态再取色板（实测改后批次条 `#35c8b4`）。
2. **nord success 对控件底仅 4.23:1**（AA 要求 4.5）：`#a3be8c`→`#aec79a`（4.70:1）。
   此前 `test_g70_ui_upgrade` 只查了 error 色，success 一直未被覆盖。
3. **失败汇总「操作」列把按钮文字裁成「重试该类」**：`QTableWidget::item` 的全局 padding 吃掉了
   `setCellWidget` 的可用宽度。修法：去掉该全局 padding + 操作列改 `ResizeToContents`。
4. **`@pyqtSlot(int, str)` 装饰器错位**到新增的零参 `_strip()`（重构时插入位置错误）。
5. **`theme="auto"` 时 `apply_theme("auto")` 会退化成 deep**：`_themed_qss` 改为只在设置值
   是真实主题键时才写模块状态，auto 交由 `_maybe_apply_system_theme` 解析后写回。

### 2.3 守卫（新增 43 项，见 `tests/test_g75_visual_system.py`）

- 字号阶梯 7 级且**严格递减、互不相同**；基体 13px 不变（历史断言依赖）。
- 三字族链各自有回退，末端必为 `sans-serif` / `monospace`；中文永远有回退。
- 四主题键集合一致；正文 ≥4.5:1（hc ≥7）、次文本 ≥4.5、语义色 ≥4.5、边界 ≥3、`on_cta/cta` ≥4.5、`accent/bg` ≥3。
- **反 AI 通用美学**：默认主题不得是 `#0d1117`/`#58a6ff`/`#3fb950`；主按钮不得用强调色填充。
- 4 主题 × 3 缩放 × 2 动效 = 24 组 QSS 通过 `qss_validate`；`motion=False` 时无 hover 块。
- 7 种状态形状互不相同且**真的画出像素**（`QPainter` 上色计数）。
- 齿条：空态全 `—`、空闲不起定时器、注入时钟验证用时冻结。
- 接线：齿条挂在主窗中央控件、pill delegate 挂第 2 列、状态文本仍为纯文本、导航 `01–07` 无工程代号。
