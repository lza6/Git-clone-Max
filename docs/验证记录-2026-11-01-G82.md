## 追记：CI 三平台 hotfix（ca86ce3，2026-11-01）

发布后 main CI（e37b511）三平台红，两个根因都在本机被掩盖：

1. **changelog.py UnicodeEncodeError**：CI Windows stdout=cp1252，中文 `[OK]` 直接崩。
   本机 UTF-8 控制台掩盖 → 脚本入口 `reconfigure(encoding="utf-8")`。
2. **macOS Abort trap 6**：`_Aggregator` 以对话框为 parent，对话框在线程运行中被析构
   （test_statistics_dialog_more 触发）→ parent=None + finished→deleteLater；
   本机 30 次构造+立即关闭压力复现通过。
3. **workflow_status.md 二次误入索引**（e37b511）→ git rm --cached + gitignore 防再犯；
   test_g79 白名单守卫在三平台按设计拦截（守卫有效性实证）。

连带：test_g44 两处 StandardButton 用 Mock 冒充真枚举 → 改真 QMessageBox.StandardButton；
plugin.json 版本残留；winget sha256 重生成；except 基线 614/283 逐条登记。

**教训**：本机控制台 UTF-8 是一层伪装 —— 凡 print 中文给 stdout 的脚本，编码必须脚本内自保证；
QThread 的 parent 语义与直觉相反（parent 析构 = 线程被销毁），一律 parent=None + 引用持有。

## 追记 2：host 闸门票泄漏死锁（hotfix4，8d18fc5/22607a7）

CI slow job（POSIX 真实 git E2E）28 分钟挂死 → 取消 → 本地复现。

**定位链**：`faulthandler.dump_traceback_later(40, exit=True)` dump 显示 8 个
pooled 线程全卡 `worker.py` acquire 循环 → 票值探针（`_value` 打印）实锤
4 个 worker "after run" 时 `value=0` → release 从未执行。

**根因**：b7dbaa9 审查修复引入 —— 替换脚本丢失 `self._gate_held = acquired`
赋值行，`finally` 的 `getattr(self, "_gate_held", False)` 恒 False → 4 张票
永久泄漏 → 同 host 第 5 个 worker 起永久阻塞。

**修复+守卫**：补赋值行；新增 `TestGateLeakThroughWorkerRun` 双路径守卫
（SimpleNamespace 直构 CloneWorker，Mock(spec=) 的属性陷阱曾致测试假绿）。
变异实验：注释赋值行 → 异常路径 `0 != 1` 红 → 恢复 → 绿。

**卡死测试**：60s+ 挂死 → 4.6s；slow 十模块本地 129 tests OK（55s）。

**教训**：①替换式补丁必须 diff 自检（heredoc 转义三次吃行）；
②并发原语改动必须跑真实并发峰值**全路径**（老测试直接 gate.acquire
未走 CloneWorker.run —— 覆盖缺口）；③`mock.Mock(spec=X)` 把 spec 变
只读属性，`self.payload.spec` 会 AttributeError 提前退出 = 假绿。
