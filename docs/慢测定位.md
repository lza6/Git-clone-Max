## 6. pyinstrument 定位工作流（2026-11-13 引入）

> 工具已进 `requirements-build.txt`（pyinstrument==5.0.3），与 ruff/mypy 同一安装链。
> 用法：把「哪一节慢」的猜测变成可复现证据，采样结果默认输出调用树 + % 时间占比。

```bash
# 定位单个慢测试文件（快集口径，offscreen 必须）
QT_QPA_PLATFORM=offscreen ./.venv/Scripts/python.exe -m pyinstrument -c "
import unittest, sys
sys.argv = ['x', 'tests.test_xxx', '-v']
unittest.main(module=None, argv=sys.argv[1:], exit=True)
"

# 定位引擎热点（非测试）：真克隆 octocat 一轮
QT_QPA_PLATFORM=offscreen ./.venv/Scripts/python.exe -m pyinstrument -c "
from gcm.git.service import GitService
import tempfile, os
d = tempfile.mkdtemp()
s = GitService(d)
print(s.sync('https://github.com/octocat/Hello-World'))
"
```

纪律：**先跑一遍目标测试记录耗时基线，再上 pyinstrument 对照**——没有前后对比的采样只是好奇心的开销。

## 7. 规模与泄漏基线（`scripts/bench_scale.py` / `mem_soak.py` 可复算）

> 此前所有"能不能撑住几千仓库"的判断都靠估。这两个脚本让它变成可复算的数字。
> 命令：`python scripts/bench_scale.py` · `python scripts/mem_soak.py --rounds 500`

### 7.1 规模（本机 Windows / Python 3.14.3 / WAL）

| 指标 | 500 仓 | 1000 仓 | 3000 仓 |
|---|---|---|---|
| 建库+灌数据（一次性） | ~1.1s | 2.23s | 6.88s |
| `db.list_repos()` 全量 | — | 3.91 ms | **14.18 ms** |
| `db.list_repos_page(50)` | — | 0.38 ms | **0.71 ms** |
| `db.search_repos()`（LIKE 下推） | — | 1.01 ms | **3.90 ms** |
| `ManageModel.set_rows()` | — | 1.21 ms | **4.09 ms** |
| 表格首帧（3 次 processEvents） | — | 0.05 ms | 0.14 ms |
| `dir_stats` 命中（3000 条批量） | — | 1.14 ms | **3.92 ms** |

**结论（用于否决"必须分页"的旧假设）**：3000 仓库下管理页全量取数 + 建模 + 首帧
合计约 **18ms**，远低于任何人类可感知阈值。**分页不是当前瓶颈**；真正的瓶颈是
`dir_size` 的递归 stat（见 7.2）与 `prune_history`（已挪出热路径）。

### 7.2 目录大小与历史治理

| 场景 | 实测 |
|---|---|
| `Database.dir_size()` 6 万文件（300 仓 × 200 文件） | 63 ms |
| `Database.dir_size()` 15 万文件（50 仓 × 3000 文件） | **484 ms** |
| `dir_stats` 缓存命中（3000 条） | **3.92 ms**（C3-1 落库缓存） |
| `prune_history()` @ 10 万行 | **238 ms**（C3-2 已挪到批次收尾，不再每 100 条触发） |

### 7.3 长时挂机内存（`scripts/mem_soak.py`）

| 轮数 | tracemalloc 当前 | 峰值 | 事件缓冲 |
|---|---|---|---|
| 500 | **276.4 KiB** | 294.4 KiB | buffered=700（events 500 + progress 200） |
| 2000 | **279.7 KiB** | 297.7 KiB | buffered=700（同上） |

**结论**：轮数 ×4 而内存几乎不变 → 事件环形缓冲**有界**，该链路无随轮数增长的累积。
（`psutil` 未安装时脚本只报 tracemalloc 数字，RSS 列显示 0 —— 属预期降级。）
