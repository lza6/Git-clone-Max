## 提速建议（G50-3 落地路径）

1. **本地裸仓 + 网络隔离**：真实 git E2E（clone/update/conflict）一律改本地裸仓（`git init --bare` 于临时目录），去掉对 github.com 的网络依赖，同时消除网络抖动导致的 flaky。
2. **`GIT_CONFIG_NOSYSTEM=1`**：抑制系统级 git 配置读取，省 I/O 与配置合并。
3. **慢测独立 job**：CI 增加 `slow` job（`unittest discover -p "test_engine.py" -p "test_v7_fixes.py" -p "test_core.py" -p "test_extra.py" -p "test_v3_p0.py" -p "test_submodule.py"`），主测试 job 只跑非慢集，默认全量 ≤600s。
4. **README 登记快速冒烟命令**：`python -m unittest discover -s tests -p "test_core.py" -p "test_engine.py"` 之外的快速子集（如 `tests/test_redact.py tests/test_g38_network.py`）用于本地快速反馈。

> 注：本节为**分析文档**（G50-3 的定位部分），未改动任何测试代码；实施提速属 G50-3 后续动作，需 TDD + before/after 计时登记。
