## 3. 关键断言

1. **日志落盘**：`https://user:pass@...`、`Authorization: Bearer ...`、`PRIVATE-TOKEN`、
   `ghp_...` 不落明文；普通日志原样保留。
2. **打码变体**：`C:\Users\Alice`、`C:/Users/Alice`、`\\server\users\Bob`、
   `Documents and Settings\Carol` 均 mask；40 位 commit SHA 不被误伤。
3. **原子写**：`PermissionError` 前两次失败、第三次成功（retries 生效）；
   非瞬时 `OSError` 立即上抛且清理 tmp；mkstemp 无 `.tmp` 残留。
4. **诊断包**：4 线程并发导出同一路径无异常、zip 可读、无 tmp 残留；
   report 超 2MB 截断且 manifest `report_truncated=true`；
   manifest 含 `timezone` / `redaction_version=2`。
5. **重试抖动**：注入 `jitter=lambda d: d/2` 时 `next_retry_at=1015`；
   `due_tasks(limit=2)` 只返回 2 条。
6. **SSE 续传**：`Last-Event-ID` 只补发 seq 之后的事件，不重复旧事件；
   并发上限 1 时第二条连接得到 503 + `Retry-After: 5`。
7. **订阅者指标**：慢订阅者 `dropped>=1`、`qsize<=1`、label 正确。

## 4. 未运行 / 边界

| 项 | 原因 | 补偿 |
|----|------|------|
| 真实浏览器 EventSource | 环境无浏览器工具 | 原生 `http.client` 按 Last-Event-ID/503/心跳逐帧验证 |
| HTTP/1.1 chunked | `BaseHTTPRequestHandler` 不自动分块，收益低、回归面大 | 明确不实施，保留 HTTP/1.0 close-delimited |
| Windows winerror 精确模拟 | 需管理员/文件占用场景 | `PermissionError` 路径已测；winerror 集合静态确认 |
| DLQ 可视化 | UI/i18n 工作量 | 列入下一轮 backlog |
| 远程平台网络克隆 | 外部依赖 | 本地裸仓 E2E 覆盖 |
