## 3. 关键行为断言（测试覆盖点）

1. **事件总线**
   - 发布/订阅顺序、`seq` 单调；`replay` 也遵守 `types` 过滤；
   - 出站打码：URL userinfo / `Authorization: Bearer` / query token 均不出明文；
   - 慢订阅者（queue=2）丢最旧、`stats.dropped>0`，发布不阻塞；
   - `close()` 能唤醒等待者。
2. **SSE**
   - `Content-Type: text/event-stream`；首帧 `retry: 3000` + `: connected`；
   - 连接后发布事件可读到 `id/event/data` 帧；`replay` 能补发连接前事件；
   - `replay=-1` / `heartbeat=999` / `snapshot?limit=0` → 400；
   - 事件端点不打开数据库（长连接不占 SQLite 连接）。
3. **错误模型**
   - 网络超时 / 429 / 5xx → `retryable=True`；
   - 401/403 / 404 / 磁盘满 / 平台限制 → `retryable=False`；
   - 三段式 `display_lines()` 恰好三行。
4. **重试队列**
   - `record_failure_ex` 返回 `queued/reason/attempts/next_retry_at`；
   - 超限 → `reason=exhausted` 且进入 `dropped`；
   - `retry_now` 把 `next_retry_at` 置 0；`stats.due` 同步；
   - `path=None` 纯内存模式**真实保留记录**（修复前记什么丢什么）。
5. **原子写**
   - 4 线程 ×30 次并发写同一 JSON：无异常、最终 JSON 合法、无 `.tmp` 残留；
   - 4 线程并发 `mark_finished`：8 条记录全部保留（无丢失更新）。
6. **诊断包**
   - zip 含 `manifest.json/report.txt/events.jsonl/app.log/notify.log`；
   - manifest `tool/version/events` 正确；
   - `supersecret` / `user:pass` / `token@host` / `PRIVATE-TOKEN` 均不出现。
7. **状态机**
   - queued→running→终态；终态重复 mark 幂等、回退被拒且计入 `invalid_transitions`；
   - queued 可直接 skip/cancel。
8. **引擎发布**
   - `_on_result` 成功 → `task_result`；失败 → `task_result` + `task_error`（category/retryable）；
   - 失败且启用重试 → `retry_queued`（attempts=1），`engine.retry_queue.count()==1`。
9. **GUI 本地 API 设置**
   - 默认关闭、端口 8765；保存回调真实触发 `_apply_local_api_settings()`（不是只存字段）。
10. **事件流查看器**
    - 默认过滤掉 `task_progress`；`progress/errors/retry/batch` 模式纯函数断言；
    - 面板刷新/复制 JSON 读取同一份 EventBus 快照。
