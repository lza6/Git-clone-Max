# 验证记录 — 2026-10-20（G74 UI 布局与可读性 · v9.8.3）

## 1. 范围

用户反馈「UI 界面还有很大问题」，要求实际启动、截图、自行排查并修复。
本轮不新增业务能力，只处理**真实截图里可见**的布局/可读性/主题/文案缺陷。

### 1.1 第一轮（布局骨架）

- `gcm/ui/download_layout.py`：主操作区移出顶部滚动区（任何分辨率可见「开始/取消」）；
  快捷填充改横向滚动、任务清单独立一行；去掉按钮装饰 emoji。
- `gcm/ui/main_window.py`：下载页 `top_container` = 滚动区（仅输入/位置/模式）+ 固定操作区；
  compact 隐藏快捷填充；设置导航短标题 + tooltip；设置滚动区关闭横向滚动。
- `gcm/ui/manage_panel.py`：工具栏拆统计行/主操作行/次操作行，搜索框最小 180px。
- `gcm/ui/settings_groups.py`：启动组 6 个复选框改 2 列网格；SpinBox 限宽。
- `gcm/ui/progress_table.py` / `progress_delegate.py`：详情列 Stretch + 省略；状态纯文本。
- `gcm/ui/theme.py`：字体栈补 Symbol/Emoji fallback；新增 `apply_parent_theme`。

## 3. 关键断言（`tests/test_g74_ui_layout.py`）

1. 1024×768 下「开始/取消/诊断包」可见，且**不在** `download_top_scroll` 内。
2. Compact 隐藏快捷填充；标准宽度恢复可见，横向 `ScrollBarAsNeeded`。
3. 管理搜索框 180–400px；管理表时间列 Fixed 且 ≥150px。
4. 设置导航无长括号标题、无横向滚动；SpinBox 为 `NoButtons`。
5. QSS 含 `QLabel, QCheckBox, QRadioButton` 透明规则与 `QSpinBox::up-button` 兜底。
6. 进度表详情列 Stretch；状态文本不含 ✓/✕/⚠/⊘。
7. 诊断对话框继承主窗 QSS（长度 >100）；统计中心含 QScrollArea。
8. 空输入时校验标签隐藏；输入有效地址后显示「有效 1」。
9. 重试 DLQ 行包含「网络连接失败」与处理建议，而不只是标题。
10. 清单关闭按钮为「关闭」；详情页长路径含省略号且 tooltip 为完整路径。

## 4. 边界

- 截图来自 **offscreen** 渲染（真实事件循环 + 字体注册），不是真机鼠标点击；
  CI 不含 GUI 截图对比（无像素基线）。
- 统计中心/失败汇总在极小高度仍需滚动（已有 QScrollArea/QTable 滚动条），未做自适应折叠。
- `checkbox` 透明规则是全局的：若将来某控件**需要**在标签上画底色，需显式覆盖。
- 未做多语言全量截图（仅中文）；英文文案由 i18n 单测与 key 完整性守卫覆盖。
