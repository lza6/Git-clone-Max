## 8. G80-B4-1（检出校验）

```
$ QT_QPA_PLATFORM=offscreen python -m unittest tests.test_g80_checkout_visible -v
6 例：正常克隆 ok / 工作树清空 missing+FAILED+目录保留 / 裸仓库 skip / 空仓库 EMPTY / 目录不存在 missing / 枚举仍 7 个
Ran 6 tests in 1.511s
OK
```

**实现**：`Service.sync()` 包一层 `_finalize_checkout(_sync_inner())` —— 在**唯一出口**补校验，
而不是往 6 条成功分支各插一次。裸仓库先判 `rev-parse --is-bare-repository` 再决定 skip；
`missing` 降级为 FAILED 但**保留 `.git`**（下次重试增量补齐），detail 三段式。

**实现**：`Content-Length > 1MiB → 413`（先看头后读体，不读 body）；`format` 白名单外 → 400

`gcm/db/repo_search.py`。
