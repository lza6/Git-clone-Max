## 2. 批次 A（v10.0）：agent / 自动化能力补全

> 这些是 Rev6–Rev7 时代评估过、**有真实外部参考验证过机制**、至今 `grep` 代码库**零命中**的项。
> 本轮已逐一用 `grep -rln` 复测确认仍不存在（`已验证`）。

### A-1 · 批次 `plan.json` + preview→apply 两段式 + `--dry-run` 【P0】

- **现状**：`grep dry_run` / `batch_plan` 在 `gcm/` **零命中**。所有破坏性批次一旦执行不可逆。
- **参考**：ghorg `--dry-run`、zoekt 默认 preview、`-f` 才落地。
- **落地**：新增 `app/batch_plan.py` 纯函数（`specs + 本地状态 → [clone/fetch/skip/prune +
  原因 + 预计字节 + 本地改动保护标记]`）；UI 一张差异表；`--cli --dry-run` 输出同一份 JSON；
  MCP `clone_batch` 增 `dry_run` 参数复用同一实现。
- **验收**：纯函数单测覆盖空批次/全跳过/本地改动保护；CLI E2E 断言 dry-run 零子进程 git 写操作。

### A-2 · 面向用户的「git 命令日志」面板 【P0】

- **现状**：`grep -rln "GitCommandLog|git_command_log"` 零命中；排障只能翻 `app.log`。
- **落地**：`git/service.py` 统一执行入口收口处记录 `{argv(过 redact), cwd, elapsed_ms,
  exit_code, stderr 尾部}` 进环形缓冲；进度表右键「查看该仓库的 git 命令」。
- **验收**：缓冲有界（防内存膨胀）；打码断言（token/URL 凭据不出现在面板）；真实克隆一轮后面板非空。

### A-3 · 操作台账 oplog + 撤销 【P1】（Rev7 C6 尾巴，唯一未做项）

- **现状**：确认框有、撤销无（`grep oplog` 零命中）。
- **落地**：append-only 表 `oplog(id, ts, action, target, before_json, after_json, undoable)`；
  只对**可逆**动作登记（删记录、改标签、清队列）；`git clean` 类不可逆动作只记录不承诺撤销。
- **依赖**：建议排在 A-1 之后（plan diff 是 oplog 的天然输入）。
- **验收**：撤销往返测试（做→撤→状态一致）；不可逆动作断言**不出现** undo 按钮。

### A-4 · prune 三态 【P1】（依赖 A-1/A-3）

- **现状**：远端删库后本地永久残留，且"删本地"无三态控制（`grep prune_untouched` 零命中）。
- **落地**：`--prune` / `--prune-untouched` / `--no-clean` 三态；只删「远端不存在 **且** 本地无改动
  **且** 用户在 plan 预览里勾选」的仓库；三态语义进 `--json` schema 与 agent-contract。

### A-5 · 外部过滤钩子 `--repo-filter-hook` 【P1】

- **现状**：零命中。让"克隆哪些仓库"可被用户脚本决定（按语言/大小/许可证）。
- **落地**：列表 JSON 进 stdin、读回 stdout 决定取舍；**必须二次确认**（任意命令执行面，
  参照 `settings_actions.py` 既有范式）；超时 + 打码 + 只读 stdin 协议；仅 CLI 与设置页高级区暴露。

### A-6 · 令牌走外部命令 `token_cmd` 【P2】

- **现状**：自研 `_encrypt_token`（DPAPI/keyring/XOR 降级）落盘；`grep token_cmd` 零命中。
- **落地**：新设置字段 `token_cmd`（写侧+读侧+生效断言，遵守 S41 接缝纪律）；执行时 5s 超时、
  失败降级回既有加密存储、输出过 `redact`。

### A-7 · `gcm://` 协议处理器 【P2】

- **现状**：零命中。低工作量高感知：网页点仓库链接直接进队列。
- **落地**：`HKCU\Software\Classes\gcm`（免管理员）；参数解析复用 `url_lib`；
  GUI 启动参数接收 `gcm://` URL；守卫：恶意超长 URL / 非法 host 拒绝。
