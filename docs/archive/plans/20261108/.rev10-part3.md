### Q-01 · `scripts/bump_version.py`（8 处载体，一次原子完成）

**状态**: DONE（v9.18.0 G84-B1：10 类载体 + dry-run + 自跑守卫 + 失败回滚，tests/test_g84_bump_version 9 例）

- **目标**：版本 bump 从「手改 8 处」变成「一条命令 + 自校验 + 失败回滚」。
- **证据**：`scripts/bump_version.py` **不存在**；v9.17.0 那次 bump 实测漏了 3 处（`decisions.md` D-G83-3）；
  本轮实测 8 处载体**当前值均为 9.17.0**（`已验证`）：`gcm/__init__.py:18` · `pyproject.toml` ·
  `Git-clone-Max.spec:59,63`（`FileVersion` + `ProductVersion` 两处）· `packaging/installer.iss:10` ·
  `packaging/winget/lza6.Git-clone-Max.yaml:3` · `.claude-plugin/plugin.json:3` ·
  `docs/contract/cli_json.schema.json:42` · `docs/agent-contract.md:3,30,112`（+ README 版本行）。
- **落地规格**：
  - `bump_version.py <X.Y.Z> [--dry-run]`：先在**内存里**算出每处的新内容并打印 diff；
    `--dry-run` 只打印；正式执行时**逐个文件原子写**（`util/atomic_io.write_text_atomic`），
    任一失败 → **把已写的文件全部回滚**（保留原文本快照）。
  - 改完自动跑：`python scripts/doc_drift_check.py` + `python -m unittest tests.test_g66_patch -v` +
    `python -m unittest tests.test_g81_changelog -v`；任一红 → 打印「bump 未完成，已回滚」并以退出码 1 结束。
  - `--check` 模式：只校验 8 处载体与 `__version__` 是否一致（给 CI 用，替代现有分散断言）。
- **验收**：在临时副本仓库上跑 `--dry-run` 断言 8 处全部命中；故意把手改一处 → `--check` 报错并点名该文件。
- **工作量**：S~M（3~6 小时）
- **风险**：它自己会改 `__version__`（自举风险）→ 用 `--dry-run` 先验证，再真跑，跑完立刻 `git diff` 人眼过一遍。
