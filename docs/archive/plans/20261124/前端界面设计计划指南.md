> **文档定位**：本文件是「界面设计与美学纪律」的**计划 / 执行手册**，不是事实源。

## 0. 一句话立场

本项目是 **PyQt6 桌面应用**，不是 Web 页面。所有 Web 前端惯例（Tailwind / Shadcn / CSS 渐变 / 网页字体）**不直接适用**；
本项目的「反 AI 通用美学」已经落成一套 Qt 语境的纪律：**仪器感、单强调色、形状编码、token 唯一来源、守卫测试锁死**。
本指南回答：在这一纪律下，如何规划、评审、落地每一个新界面与每一次视觉改动。

## 1. 适用范围

| 适用 | 不适用 |
|---|---|
| `gcm/ui/` 全部界面与自绘控件 | Web 前端（本项目无浏览器端） |
| QSS / 色板 / 排版 / 动效 / 布局改动 | `gcm/app`、`gcm/db`、`gcm/git` 的非视觉逻辑 |
| 新增对话框、面板、表格、状态展示 | 纯命令行输出（`gcm/cli.py` 文本格式另有契约） |

**项目背景**：Git-clone-Max 是批量并行克隆 + 增量更新 + 入库追踪的桌面工具，
目标用户是「挂着刷几百个仓库」的个人开发者；核心诉求是**长时间盯批次进度不累、状态一眼可读**。

## 2. 设计四问（本项目已确立的答案）

| 问题 | 本项目的答案 | 依据 |
|---|---|---|
| **PURPOSE 目的** | 让用户在批量克隆的长流程里，一眼读出「多少成功 / 多少在跑 / 哪个失败了、为什么」；失败时给出可操作的重试路径 | `design-system.md` §1；`failure_panel.py` / `retry_panel.py` / `batch_conclusion.py` |
| **TONE 调性** | **仪器，不是模板**：近墨黑 / 暖纸底、骨白文字，唯一的强调色只表达「正在发生」。克制、精确、工程感；拒绝营销页式的渐变与发光 | `palettes.py` 模块注释；`design-system.md` §1–2 |
| **CONSTRAINTS 限制** | Qt QSS 能力边界（无 `box-shadow`）、系统字体三族（不打包 ttf）、最小 900×480 逻辑像素、WCAG 对比度硬指标、禁字符符号（缺字形 tofu） | `design-system.md` §2/§4/§10 |
| **DIFFERENTIATION 独特性** | ①「示波器青」强调色语义（只给进行中）；② 状态用 7 种几何形状而非字符；③ 骨白反相块做主操作（不是 GitHub 蓝）；④ 卡片顶部 1px 内嵌高光代替阴影 | `palettes.py`、`status_pill.py`、`design-system.md` §2/§6 |

## 3. 反「AI 通用美学」→ 桌面落地对照表

Web 语境的通用禁令，在 PyQt6 里对应如下纪律（**全部已有守卫或既有实现**）：

| Web 上的 AI 通用反模式 | 本项目的桌面对应纪律 | 守卫 / 实现 |
|---|---|---|
| 滥用 Inter / Roboto | 只用系统三族：Bahnschrift（显示/数字）、Microsoft YaHei UI（中文）、Cascadia Mono（数据/日志）；不打包 ttf、不联网下载 | `typography.py`；`test_g46_theme` / `test_rev11_visual` |
| 蓝紫 #4F46E5 + 彩虹渐变 | 四套主题色板唯一来源 `palettes.py::PALETTES`；强调色 6 档预算制，**accent 只表达「正在发生」**，单份 QSS 出现 ≤9 次 | `test_g75_visual_system` / `test_rev11_visual` |
| 12 栏对称卡片墙 | 桌面分区用 `panel` / `panel_primary`（每屏至多 1 个最高权重卡面）+ 4pt 网格间距，不对称的信息层级 | `qss_build.py`；token 守卫 `test_rev14_feedback` |
| 全局 `transition: all .3s` | 动效只来自 `motion.py` 四档时长 + 统一 `OutCubic`；`prefers_reduced_motion` 时全部跳过 | `motion.py`；`design-system.md` §5 |
| 纯色单调背景 | 层次用 1px 边框 + 1px 顶边 `glow` 内嵌高光表达（QSS 无阴影能力，刻意不用图片/噪点堆砌） | `palettes.py` `glow` token；`qss_build.py` |
| 无意义悬停淡入淡出 | hover/pressed 只在 QSS 有语义处出现；运行态用 `signal_dim` 弱化描边而非加动画 | `qss_build.py`；`palettes.py` 注释 |

> 结论：**不要**把 Tailwind / Shadcn 引入本项目（QSS 只由 `qss_build.py` 生成并缓存，
> 引入 CSS-in-JS / Tailwind 属于架构红线）。独特性来自「语义纪律 + 几何形状编码 + 色彩预算」，
> 不来自堆视觉特效。

## 4. 五大支柱执行细则

### 4.1 排版

- 角色字号唯一来源：`typography.py` + `design-system.md` §4 的角色表
  （display 28 / h1 20 / metric 18 / h2 15 / body 13 / mono 12 / small 11）。
- 基体 `FONT_BASE_PX = 13`；缩放 `font_scale ∈ [0.9, 1.6]`；DPI≥150% 时 `clamp_scale_for_dpi()` 抬到 ≥1.0。
- **陷阱**：QSS 的全局 `QWidget { font-size }` 会覆盖 `apply_type()` 的 QFont。
  需要角色字号的控件用 objectName（`#pageTitle` / `#display` / `#metric` / `#kicker` / `#monoLabel` / `#emptyHint`）。
- 数字 / URL / 路径 / 时间一律 `mono`（Cascadia Mono）右对齐。

### 4.2 色彩与主题

- 色值只放 `palettes.py`；四套主题（deep / light / nord / hc）键集合必须完全一致。
- 对比度硬指标：正文/弱文本 ≥4.5:1；输入边界 ≥3:1；`on_cta/cta` ≥4.5:1；`hc` ≥7:1。
- **改任何色值 = 重跑 4 主题 × 6 强调色 = 24 组对比度矩阵**（`test_g70_ui_upgrade` + `test_g75_visual_system`），不许抽样。
- `theme.current_palette()` 是**唯一**颜色来源：自绘 delegate、日志高亮、托盘图标、状态 pill 全部读它，禁止第二份色值。
- accent 预算：进度 chunk、焦点环、运行中 pill 可用；页签选中（用字重 + 中性下划线）、kicker 铭牌（用 text_dim）、静态装饰**禁用**。

### 4.3 动效

- 唯一来源 `motion.py`：`BASE_MS=220`（状态切换）、`PULSE_MS=180`（终态脉冲）、`SLOW_MS=600`（行完成消隐）、`FAST_MS=120`（微反馈：复制成功按钮回弹，event_panel 消费）。
- 统一 `OutCubic`；`prefers_reduced_motion=True` 时 QSS 去掉 hover/pressed，动画全部跳过。
- 不做持续 shimmer；骨架屏用静态占位（`skeleton.py`）。桌面工具不加 400ms 模态动画。

### 4.4 空间构图

- 4pt 网格：新/改组件只用 4/8/12/16（`TOKENS.spacing.*`）。存量 6/10/14 **不批量替换**，只在被本轮触碰的组件里顺手收敛。
- 布局档位：XS（`w<1020` 或 `h<580`）/ S（`w<1100` 或 `h<820`）/ M / L（`w≥1440 且 h≥1000`），实现见 `layout.py`。
- 已确立的不对称分区：设置页 72/28 可调 Splitter；窄窗 <1000 时分组导航从左列改为顶部下拉；管理页 <1100 隐「健康/大小」列。
- 表格行高 26/28/34 三档；触摸屏主操作 ≥44px、行 ≥34px。

### 4.5 背景与视觉细节

- 层次表达：`panel` / `panel2` / `panel_primary` 三档卡面 + `border` / `border_strong` / `signal_dim` 三档描边 + 1px `glow` 顶边高光。
- **禁止**为「氛围」引入噪点纹理图、大面积渐变、玻璃拟态 —— Qt QSS 做不出高质量版本，且与仪器感冲突。
- 日志区：Cascadia Mono 12px，最多 4000 block，过滤只影响显示层。

## 5. 新增 / 修改界面的标准流程

1. **读事实源**：`docs/design-system.md` 对应章节 + 被改区域的既有模块（先看 §10 引用索引）。
2. **定位落点**：新 UI 逻辑一律落**独立模块**（先例：`failure_panel` / `progress_table` / `event_panel` / `settings_actions` / `download_layout` 等）；**不得再往 `main_window.py` 塞**。新模块目标 200–400 行，硬上限 800 行；函数 ≤50 行；嵌套 ≤4 层。
3. **先写守卫再动手（TDD）**：视觉断言进对应测试文件（改色 → 对比度矩阵；改 token → 死键守卫；改布局 → 档位测试）。
4. **token 优先**：颜色读 `current_palette()`，间距/圆角/行高用 `TOKENS`；没有的 token 先问「是否真有消费点」，有才加，否则用现有组合。
5. **QSS 只进 `qss_build.py`**：不散落 `setStyleSheet`；自绘控件用 `QPainter` + palette 色值。
6. **状态编码**：颜色 + 形状双编码（`status_pill.py` 的几何形状）；**禁止** `✓ ✕ ⚠ ⊘` 等字符符号（微软雅黑缺字形 → tofu）。
7. **跑变更-验证矩阵**（§7）→ 同步 `docs/design-system.md`（代码与文档冲突时以代码为准，同一次提交里修文档）→ 需要用户可见文案时走 `tr()` 并同时补 `zh.py` / `en.py`。

## 6. 禁止事项（红线清单）

- 禁止引入 Tailwind / CSS-in-JS / CSS modules；QSS 只由 `qss_build.py` 生成。
- 禁止在 `palettes.py` 之外写死色值；禁止第二份主题表。
- 禁止使用字符符号表达状态（✓ ✕ ⚠ ⊘ → tofu）。
- 禁止 `box-shadow`、噪点纹理、大面积渐变、玻璃拟态。
- 禁止 accent 做静态装饰（页签选中、kicker、装饰描边）。
- 禁止打包 ttf / 联网下载字体；只用系统三族。
- 禁止绕过 `motion.py` 自起 QTimer 动画；`prefers_reduced_motion` 必须被尊重。
- 禁止为「好看」牺牲对比度：24 组对比度矩阵不抽样、不放宽阈值。
- 禁止把新 UI 逻辑塞进 `main_window.py`；禁止新增超 800 行模块。
- 禁止无断言的「视觉验证」；截图审计（`ui_screenshot_audit.py`）只作目检辅助，不替代守卫测试。

## 9. 自检清单

**设计阶段（写代码前）**
- [ ] 明确这个界面帮用户读出什么状态（PURPOSE）
- [ ] 沿用「仪器感」调性，没有引入 Web 特效冲动（TONE）
- [ ] 确认 QSS / 字体 / 对比度约束都满足（CONSTRAINTS）
- [ ] 至少一处「状态可辨」的设计（颜色 + 形状 / 字重 / 层级），而非装饰性独特（DIFFERENTIATION）

**实现阶段**
- [ ] 色值全部来自 `current_palette()` / `palettes.py`
- [ ] 间距/圆角/行高全部来自 `TOKENS`，新 token 有消费点
- [ ] QSS 只写在 `qss_build.py`；无散落 `setStyleSheet`
- [ ] 动效来自 `motion.py`，尊重 `prefers_reduced_motion`
- [ ] 新 UI 逻辑在独立模块，未撑大 `main_window.py`
- [ ] 用户可见文案走 `tr()`，zh/en 字典同步

**品质阶段**
- [ ] §7 矩阵对应测试全绿；`ruff` / `mypy` 绿
- [ ] 四主题 + 六强调色下目检截图无对比度 / 裁切 / tofu 问题
- [ ] `docs/design-system.md` 已与代码同步
- [ ] 无未验证就宣称「已完成」的结论（证据标签：已验证 / 静态确认 / 合理推断 / 待验证）
