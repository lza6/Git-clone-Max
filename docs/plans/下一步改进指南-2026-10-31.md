| **V1 团队共享仓库池** | 一个小团队各自克隆同一批仓库，磁盘/带宽重复浪费 | 需要一个局域网内可发现的服务端（`git daemon`/静态 HTTP 即可，不必 SaaS）；先有 B5-3 事件持久化与多实例共享 DB 的并发方案 | 会打破"桌面单机、无服务端"的既有边界（`policy.md` §4），需要重写并发与锁假设 |
| **V2 多机状态同步（git-native）** | 家里和公司两台机器想共用"仓库清单 + 标签 + 备注" | 把 `repos.db` 的可同步部分导出为**人类可读的文件**（如 `lists/*.md` + front-matter），用 git 仓库做同步通道；冲突用"最后写入 + 手工合并提示" | 双真相（DB 与文件）必然漂移，除非 DB 只做缓存 |
| **V3 插件化（fetcher / hook / 报表模板）** | 用户想接自建 Git 服务、自定义镜像算法、自定义报表 | 需要**稳定契约**（B5-2 的 schema 导出是前置）；插件沙箱与版本兼容策略 | 无稳定契约时插件化 = 永久兼容包袱 |
| **V4 SaaS 化** | 多用户/计费/团队看板 | `docs/perf-observability.md` §3 已给骨架（Gateway + PG + 对象存储 + 队列） | 与本项目"个人生产力工具"的定位冲突；需另立项目而非改造 |
| **V5 本地 LLM 辅助（离线）** | "这批仓库里哪些和我的项目相关" | 用户自备本地模型（Ollama 等），**本项目只提供检索与排序的基础设施**（B4-1/B4-2 结构化字段就是给它的输入） | 任何"调用云模型"的做法都违反付费 API 红线 |

**四条硬依赖（违反就会返工）**：

1. **A5-3（可取消/可预算的子进程执行器）必须先于 B2-2（批次暂停/恢复）**——
   暂停的语义是"等在途 git 自然退出"，而现在连"取消"都停不掉静默子进程（C-1）。
2. **B2-1（统一忙态）必须先于 B2-2/B2-3**——否则暂停/恢复与失败动作会各自再长一套状态机。
3. **B3-2（分页/窗口化）必须先于 B4-3（检索视图）**——否则 3000 仓库的检索结果集会把 UI 拖死。
4. **B5-2（schema 自动导出）必须先于 B5-1/B6-1**——否则写工具与自更新的契约会各处手写、必然漂移。

## 7. 交给执行 AI 的作业契约（直接复制到你的下一个会话）

### 7.1 开工必读（顺序不能变）

### 7.2 节点契约模板（每个批次开工前先填）

```markdown
### 节点 <ID> <一句话目标>
- 输入：要读的文件 / 已有实现（禁止重复造轮子，先查 §2.1）
- 改动范围：允许改的文件清单（逐路径）
- 禁区：不得改动的文件（如 gcm/__init__.py 版本号以外的行、.spec、i18n 生成文件）
- 交付物：代码 + 测试 + evidence json + 验证记录一节 + changelog 一行
- 验证方式：<具体命令>（定向 → 静态门禁 → 快集）
- 完成标准：<可观察的断言，如「3000 仓库检索 <50ms」>
- 依赖：<前置节点 ID>
```

### 7.3 红线（违反即判伪闭环，`policy.md` §1 已列，这里再点一次）

- 不许删/跳测试、削弱断言、mock 生产逻辑来换绿灯
- 不许把 TODO / 空实现 / 假数据 / 伪连接写成"已完成"
- 不许在没有本轮真实命令输出的情况下宣称"测试通过/构建成功/已修复"
- 不许为了清爽去重构（用户明确要求不重构）；只允许"新增落新模块 + 局部替换"

- 不许新增根目录顶层条目（先在 `_ROOT_WHITELIST` 登记理由）
- 不许真实调用付费 API（`paid_api_real_call = false`）
- 不许 `git push --force` / 改写已推送历史 / 未经授权 `reset --hard`

### 9C. 度量采集脚本（可直接复制运行，用于复核 §1 与本文件是否过期）

```python
# 建议路径：scripts/dev_metrics.py（本项目允许新增 scripts/，不参与打包）
# 用途：一次性打印 §1.3 的全部数字，避免"文档写了就信"
import ast, pathlib, re

ROOT = pathlib.Path(__file__).resolve().parent.parent

def py_files(p):
    return sorted(x for x in (ROOT / p).rglob("*.py") if "__pycache__" not in str(x))

def main():
    gcm = py_files("gcm")
    sizes = {f.relative_to(ROOT).as_posix(): len(f.read_text(encoding="utf-8").splitlines()) for f in gcm}
    print(f"gcm .py 文件数 = {len(gcm)}   总行数 = {sum(sizes.values())}")
    print("超 800 行 :", {k: v for k, v in sizes.items() if v > 800})
    print("700-800  :", {k: v for k, v in sizes.items() if 700 < v <= 800})
    longs = []
    for f in gcm:
        for n in ast.walk(ast.parse(f.read_text(encoding="utf-8"))):
            if isinstance(n, (ast.FunctionDef, ast.AsyncFunctionDef)):
                ln = (n.end_lineno or n.lineno) - n.lineno + 1
                if ln > 100:
                    longs.append((ln, f.relative_to(ROOT).as_posix(), n.name))
    print(f">100 行函数 = {len(longs)}   最大 5: {sorted(longs, reverse=True)[:5]}")
    handlers = pass_only = 0
    for f in gcm:
        for n in ast.walk(ast.parse(f.read_text(encoding="utf-8"))):
            if isinstance(n, ast.ExceptHandler):
                handlers += 1
                if len(n.body) == 1 and isinstance(n.body[0], ast.Pass):
                    pass_only += 1
    print(f"except = {handlers}  pass-only = {pass_only}   (预算在 tests/test_g80_hygiene.py)")
    print(f"test_*.py = {len(sorted((ROOT / 'tests').glob('test_*.py')))}")
    ver = re.search(r'__version__\s*=\s*"([^"]+)"',
                    (ROOT / "gcm/__init__.py").read_text(encoding="utf-8")).group(1)
    schema = re.search(r'_SCHEMA_VERSION\s*=\s*(\d+)',
                       (ROOT / "gcm/db/repo_db.py").read_text(encoding="utf-8")).group(1)
    dm = re.search(r'user_version` = \*\*(\d+)\*\*',
                   (ROOT / "docs/data-model.md").read_text(encoding="utf-8")).group(1)
    print(f"__version__ = {ver}   _SCHEMA_VERSION = {schema}   data-model.md 声明 = {dm}")
    if schema != dm:
        print("!! 漂移：docs/data-model.md 与代码 schema 版本不一致（见 A-2-1）")

if __name__ == "__main__":
    main()
```

> 运行：`./.venv/Scripts/python.exe scripts/dev_metrics.py`
> 它同时是 **B1-5 那条守卫的雏形**：把 `print` 换成 `assert` 就是 `test_doc_drift`。

### 9D. 术语表（统一用词，避免文档各自发明）

| 术语 | 含义 | 不要混用 |
|------|------|---------|
| 批次（batch） | 一次「开始」触发的整组仓库任务 | 任务 / 作业 |
| 任务（task） | 单个仓库的一次克隆或更新 | 批次 / 作业 |

| 接缝（seam） | 两个模块/进程/格式之间的边界 | 接口 / 端点 |
| 忙态（busy） | 耗时操作进行中，入口应禁用且状态可见 | loading / 加载中 |
| 用户可见（user-visible） | 会被渲染到界面或写给用户的字符串 | 内部文案 |
