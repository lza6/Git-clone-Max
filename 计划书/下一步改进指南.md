## G00 升级总纲与现状基线

**现状基线（静态确认，2026-09-10）：**

## G01 多平台直克隆与分布目录

> 核心能力缺失：`parse_repo_url` 只认 github.com（`url_lib.py:12-25`），而 `scanner.py` 已能解析任意 host。这导致「从 GitLab/Gitee/Codeberg/Bitbucket 复制地址直接下载」不可能。本模块是第一优先。

| 条目 | 优先级 | 现状 | 方案 | 落地文件 | 验收标准 |
|------|--------|------|------|----------|----------|
| `[待办]` **G01-1** | P0 | `url_lib.py` 只解析 GitHub；其他 host 一律返回 None | 重写解析为**通用 Git URL 解析器**：`parse_any_repo_url` 支持 HTTPS/SSH/短格式/带端口/子组（`a/b/c` 多段路径到仓库名）、`.`git` 后缀、`{env}` 无关；host 白名单：`github.com / gitlab.com / gitee.com / codeberg.org / bitbucket.org / git.sr.ht`；`parse_repo_url` 保持兼容故有 API | `gcm/app/url_lib.py` | 新增单测：GitLab/Gitee/Codeberg/Bitbucket/sr.ht 短格式 + SSH 各 ≥2 例解析正确；`is_github_url` 语义需拆分出 `is_git_url` |
| `[待办]` **G01-2** | P1 | 命名固定 `owner__repo`，跨 host 会同名冲突 | 命名规则升级：**host__owner__repo**（如 `github.com__lza6__Git-clone-Max`、`gitlab.com__x__y`）；host 为 github 的保持 `owner__repo` 向后兼容；同 host 下仍然 `owner__repo`。`repo_db.UNIQUE(owner,repo,host)` 已天然支持 | `gcm/app/url_lib.py` `RepoSpec.folder_name` 逻辑、`engine._dedupe_specs` | 单测：同 owner/repo 不同 host → folder_name 含 host 前缀且不冲突 |
| `[待办]` **G01-3** | P1 | `SyncEngine._service()` 固定 root=self.root；下载目录全局单一 | 支持**按 host 分布子目录**：`root/host/owner__repo`（可选，设置开关），`_repo_dir` 逻辑同步调整（`url_lib`/`git/service.py:393`） | `gcm/app/engine.py` `gcm/git/service.py` | 设置页开关「按平台分子目录」；开启后克隆到 `clones/github.com/...`，增量更新仍能找到 |
| `[待办]` **G01-4** | P1 | 输入框 placeholder 只示例 GitHub | 增加多 host 示例；快捷填充按钮保留 GitHub 常用仓库 + 可新增 GitLab 精选 | `gcm/ui/main_window.py:184-204` | 占位提示含 GitLab/Gitee 示例；UI 单测覆盖 |
| `[待办]` **G01-5** | P2 | `scanner.parse_remote_url` 对嵌套组仓库（`host/a/b/c`）解析不完整 | 与 G01-1 共用通用解析器，处理多段路径取**最后两段**为 owner/repo、前面作为路径前缀；host 判定独立 | `gcm/app/scanner.py` | 单测：`gitlab.com/group/sub/repo.git` → owner=sub, repo=repo |
| `[待办]` **G01-6** | P2 | `url_lib.host_of` 对无协议文本形如 `a/b` 无 host 识别 | 短格式解析后由 spec.host 回填；`host_of` 增加多平台白名单 + 端口剥离 | `gcm/app/url_lib.py` | 单测：`https://gitlab.com/a/b`、`git@gitlab.com:a/b.git`、`a/b`（无 host 时默认按 github）host 判定正确 |
| `[待办]` **G01-7** | P2 | 设置页与 DB 无 host 分布统计 | 管理页统计行新增「按 host 分组仓库数」标签 | `gcm/ui/manage_model.py` `main_window.py` | 管理页显示 `github: n · gitlab: m · gitee: k …` |
| `[待办]` **G01-8** | P3 | 没有「镜像/代理克隆」通用能力 | 通用 host 下支持 `GIT_MIRROR` 前缀环境变量（如 `GITMIRROR_github.com=https://ghproxy.com/`）注入 clone URL | `gcm/git/service.py` `url_lib.py` | 设置镜像后 clone URL 带镜像前缀；单测验证 URL 组装 |

## G02 核心交互增强（搜索排序/暂停/历史/导入导出）

> 下载中心当前是「静态表格 + 一次性批处理」：无过滤、无排序、无单仓库控制、地址不留档。本模块把它变成可重复使用的批处理工作台。

| 条目 | 优先级 | 现状 | 方案 | 落地文件 | 验收标准 |
|------|--------|------|------|----------|----------|
| `[待办]` **G02-1** | P0 | `QTableWidget` 无搜索过滤 | 顶部加过滤框（QLineEdit + 防抖 QTimer 200ms），按仓库名/状态实时过滤行 | `gcm/ui/main_window.py` | 键入即时过滤；空状态提示「无匹配仓库」 |
| `[待办]` **G02-2** | P0 | 无列排序（QTableWidget 需自己实现排序） | 表头支持点击排序（状态→自定义优先级排序：运行>等待>成功>冲突>失败>取消），`setSortingEnabled(True)` + 自定比较器 | `main_window.py` | 点击表头按仓库/进度/状态排序正确 |
| `[待办]` **G02-3** | P0 | 只能「取消全部」，不能暂停单个 | 引擎加**单任务取消**：`engine.pause_task(i)`（终止该 worker 并置 CANCELLED，不取消其他）；表格行内加⏸按钮/右键菜单「取消此项」 | `engine.py` `worker.py` `main_window.py` | 单任务取消不影响其他任务继续；结果槽正确标记 CANCELLED |
| `[待办]` **G02-4** | P0 | 已同步过的地址不留历史，下次要手动重敲 | 新增 `recent_urls` 历史（settings.json 或独立 `history.json`，上限 200）；输入框右键「从历史粘贴」「清空历史」 | `db/settings.py` 或新 `db/history.py` `main_window.py` | 同步成功后地址自动入历史；重开应用可从历史一键回填 |

| `[待办]` **G02-6** | P1 | 输入区无「粘贴并解析预览」 | 新增「解析预览」：`parse_urls` 结果 → QMessageBox 展示 `有效 N / 无效 M` 明细，可勾选保留 | `main_window.py` `url_lib.py` | 预览窗口正确分类大段文本 |
| `[待办]` **G02-7** | P1 | 无把一组地址存成「任务清单」的能力 | 新增「任务清单」：保存当前的 URL 列表到 JSON（名称+items），一键加载批量同步 | `main_window.py` 新 `cmds/savelist.py` 或 db 扩展 | 可保存/加载清单；清单文件可分享 |

## G04 网络与性能优化

> 网络层已具备超时/重试/代理/token/unshallow/浅克隆 depth，但缺「代理自动检测」「浅克隆 treeless/bundle」「慢网络补偿」「限速」「DNS 优选」。

| 条目 | 优先级 | 现状 | 方案 | 落地文件 | 验收标准 |
|------|--------|------|------|----------|----------|
| `[待办]` **G04-1** | P0 | 断网/超时只重试，不做**继续传播** | fetch 重试时改用 `--filter=blob:none`（GitHub 支持）提高弱网成功率；克隆失败网络类重试时加 `--config http.lowSpeedLimit` | `gcm/git/service.py` | 弱网 E2E：十次模拟失败最终以 treeless fetch 成功 |
| `[待办]` **G04-2** | P0 | `run_git_ui` 重试等待无「剩余时间/进度」提示 | 重试窗日志补「第 x/y 次 · 等待 n s · 上次原因」 | `service.py` | 重试文案含次数与原因 |
| `[待办]` **G04-3** | P1 | 代理只能手填 | 新增「自动检测代理」：读取 Windows 系统代理（`winreg`/`proxycfg`）、`HTTP_PROXY/HTTPS_PROXY` 环境变量，一键填充设置 | `settings.py`（新增 helper）`main_window.py` 设置页 | 一键检测成功填入系统代理地址 |
